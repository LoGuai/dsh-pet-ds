# 0.2.2 发布说明

> 发布日期：2026-10-21　·　安装包：`dsh-pet-ds.tgz`（约 33 MB）

## 一句话

把一个"按帧播动画"的随机动作，换成了**分三段、有时间轴、可打断**的「玩游戏」，并把仓库历史从 296 MB 瘦到 37 MB。

## 新增：随机动作「玩游戏」

替换掉原来的「玩mc」。三段素材、两段计时、两条收尾路径：

| 阶段 | 素材 | 帧率 | 何时结束 |
|---|---|---|---|
| 第一段 | `game-begin`（4 帧） | 6fps | 播完自动进第二段 |
| 第二段 | `game-loop`（2 帧） | **1fps** | 120 秒计时到点 / 被点击 → 进第三段 |
| 第三段 | `game-stop`（4 帧） | 6fps | 播完回站立闲置 |

规则细节（按需求原文实现）：

- 第二段开始时从 0 起 **120 秒**计时；
- **前两段**被点击 → **立即**进第三段，同时关掉计时（不弹部位台词、不加好感）；
- 第三段播放中点击 → 忽略，让它播完（否则会停在半截姿势）；
- **被其他动作打断**（进入深度思考、坐下、睡觉、摸头……）→ **不播第三段**，
  直接切到新动作，并把 120 秒计时关掉。

## 尺寸对齐：为什么调了三次

三段素材在美术上是**同一个站立姿态的连续动作**，但循环后半段与收尾段画得偏大
（实测头带宽 525~530 → 567 → 579，眼距 510 → 537 → 550）。前两轮都调错了方向：

| 轮次 | 做法 | 结果 |
|---|---|---|
| 第一轮 | 不缩放（scale 1.0） | 第二段第 2 帧、第三段**偏大** |
| 第二轮 | 逐帧头宽归一化到 530 | **偏小**（头发/手臂张开被误当成"变大"） |
| 第三轮（本版） | 逐帧按**整体高度**对齐站立末帧 1149px | 与站立一致 |

最终缩放：`begin 0.9991~1.0`、`loop 0.9787~1.0035`、`stop 0.9575~0.9623`；
运行时分帧率实测统一为 **0.2106 CSS px / 素材像素**，主体高 1149 vs 站立 1148（差 1px）。

画布高度仍是 **1210**（最高的收尾帧内容高 1200，1157 放不下）：多出来的高度向上溢出到
气泡区，脚底固定在 1208，切段时不会上下跳。

## 仓库瘦身

历史对象里 84% 是换 WebP 之前遗留的旧 PNG 帧（131 个文件、294 MB），
导致「仓库地址安装」必须先克隆 296 MB —— 这也是"用仓库地址装总是超时"的真正原因。

用 `git filter-repo` 从全部历史中移除 `assets/animations/*/*.png`：

| 指标 | 之前 | 之后 |
|---|---|---|
| `.git` | 296 MB | **37 MB** |
| 浅克隆 | 37 秒 | **7.6 秒** |
| 提交数 | 87 | 87（保留） |
| 7 个 tag | — | 全部重建并强推 |

工作文件逐字节未变（HEAD 树哈希 `446155f7…` 前后一致）。

## 安装方式（本版推荐）

```
install_bundle  target = https://github.com/liuguanyu9719-source/dsh-pet-ds/releases/latest/download/dsh-pet-ds.tgz
```

锁版本：

```
install_bundle  target = https://github.com/liuguanyu9719-source/dsh-pet-ds/archive/refs/tags/v0.2.2.tar.gz
```

> 不要用仓库主页地址：git 依赖要先过 5 秒预检、再克隆整个仓库，国内网络下经常超时。
